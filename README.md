# 💬 Real-Time Chat Application

A real-time chat application built using **Node.js** and **Socket.io** with a modern and responsive UI.

---

## 🚀 Features

* ⚡ Real-time messaging using Socket.io
* 💬 Modern chat UI with message bubbles
* 🔄 Auto-scroll to latest messages
* 🎨 Responsive design
* 🧠 Clean and structured code

---

## 🛠️ Tech Stack

* HTML
* CSS
* JavaScript
* Node.js
* Express
* Socket.io

## ⚙️ Installation & Setup

1. Clone the repository:

```
git clone https://github.com/HacK-2004/Chat-app.git
```

2. Navigate to the project folder:

```
cd Chat-app
```

3. Install dependencies:

```
npm install
```

4. Start the server:

```
node server.js
```

5. Open in browser:

```
http://localhost:3000
```
